One page of world news for Sunday 22 November 2026: 36 dated stories across 7 regions, drawn in code. COP31 ends with no fossil-fuel deal, 186 Russian drones over Ukraine, Iran's claim of US radar hits in Bahrain, and the rest of the day — on a single newspaper front page, with a date check that names the big stories left out because they happened on an earlier day. `main.ts` draws the 1024×1024 image deterministically with Node's standard library only: no network, no assets, two runs byte-identical.

## Run it

Requires Node 22.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
